LONGITUDINAL COMMANDS:
- follow_route

Tune longitudinal behaviour using these parameters (STRICTLY ADHERE TO THESE NAMES, DO NOT INVENT NEW ONES).
# param: min, max, default     # description
f_dist : float           2.0, 8.0, 4.0                 # desired base following distance in metres (standstill gap). Larger = more cautious
t_head : float           1.0, 2.5, 1.5                 # desired time headway in seconds. Larger = more cautious
spd    : float           0.0, speed_limit, ego_speed   # desired absolute speed setpoint in m/s (OUTPUT MUST BE NUMERIC)

LATERAL COMMANDS:
- change_lane_left
- change_lane_right

Tune lateral behaviour using these parameters (STRICTLY ADHERE TO THESE NAMES, DO NOT INVENT NEW ONES).
# param: min, max, default   # description
gap_time          1.0, 3.0, 1.5   # min acceptable time gap in target lane (ahead and behind), seconds
gap_dist          8.0, 30.0, 14.0 # min acceptable distance margins in target lane (ahead and behind), metres

CONDITIONAL COMMANDS:
- stop_for
- yield_for

Tune conditional behaviour using these parameters (STRICTLY ADHERE TO THESE NAMES, DO NOT INVENT NEW ONES).
# param           # description
target : str = {"vehicle", "cyclist", "ped", "obstacle", "stop_sign", "traffic_light"}      # The type of the target object
id     : int = actor_id                                                                     # The actor ID of the chosen target (OUTPUT MUST BE NUMERIC)

GLOBAL SAFETY AND SEQUENCING RULES
- Never change lanes inside intersections or across solid lane markings.
- Match target-lane flow speed before crossing lane boundary.
- Prefer creating a gap via slight increases/decreases in speed before initiating the lane change.
- Monotonicity: requesting higher 'spd' must NOT reduce 't_head' or 'f_dist' UNLESS changing lanes.
