LONGITUDINAL COMMANDS:
- accelerate
- decelerate
- maintain_speed

Tune longitudinal behaviour using these parameters (STRICTLY ADHERE TO THESE NAMES, DO NOT INVENT NEW ONES).
# param: min, max, default     # description
f_dist            2.0, 8.0, 4.0                 # desired base following distance in metres (standstill gap). Larger = more cautious
t_head            1.0, 2.5, 1.5                 # desired time headway in seconds. Larger = more cautious
spd               0.0, speed_limit, ego_speed   # desired absolute speed setpoint in m/s (planner clamps to speed_limit)

LATERAL COMMANDS:
- change_lane_left
- change_lane_right

Tune lateral behaviour using these parameters (STRICTLY ADHERE TO THESE NAMES, DO NOT INVENT NEW ONES).
# param: min, max, default   # description
gap_time          1.0, 3.0, 1.5   # min acceptable time gap in target lane (ahead and behind), seconds
gap_dist          8.0, 30.0, 14.0 # min acceptable distance margins in target lane (ahead and behind), metres

BRAKE COMMANDS:
- stop

The `stop` command has NO parameters (STRICTLY ADHERE TO THIS CONDITION, DO NOT INVENT NEW ONES).

GLOBAL SAFETY AND SEQUENCING RULES
- Never change lanes inside intersections or across solid lane markings.
- Match target-lane flow speed before crossing lane boundary.
- While changing lanes, keep longitudinal policy active (usually maintain_speed) with conservative headway.
- Prefer creating a gap via slight accel/decel before initiating the lane change.
- After lane change, stabilize with maintain_speed.
- Monotonicity: requesting higher 'spd' should NOT reduce 't_head' or 'f_dist'.
